## 一、场景地图系统

### 1.1 场景地图概述

场景地图是游戏的核心视觉元素，为玩家提供**可视化的空间感**和**沉浸式探索体验**。每个场景都是一个独立的可交互空间，玩家可以在其中自由移动、与物体/NPC交互、进入相邻场景。

### 1.2 场景类型定义

| 类型 | 说明 | 示例 |
|------|------|------|
| **室内场景** | 封闭空间，有墙壁、家具等障碍物 | 宫殿、房间、密室 |
| **室外场景** | 开放空间，视野开阔 | 御花园、庭院、街道 |
| **过渡场景** | 连接两个场景的区域 | 走廊、门厅、桥梁 |
| **特殊场景** | 有特殊效果或规则的区域 | 祭坛、禁地、幻境 |

### 1.4 场景地图渲染

#### 1.4.1 渲染层级

| 层级 | 内容 | 说明 |
|------|------|------|
| Layer 0 | 背景层 | 场景背景图 (1920x1080) |
| Layer 1 | 地面阴影层 | 动态阴影（角色、物体投影） |
| Layer 2 | 物体层（后） | 背景物体：柱子、墙壁装饰 |
| Layer 3 | 角色层 | 按Y轴深度排序渲染 |
| Layer 4 | 物体层（前） | 前景物体：桌子、可交互物品 |
| Layer 5 | 特效层 | 光照、迷雾、交互高亮 |
| Layer 6 | UI层 | 交互提示图标、小地图、场景信息 |

#### 1.4.2 PixiJS渲染实现

```typescript
import { Application, Container, Sprite, Graphics } from 'pixijs';

class SceneRenderer {
  private app: Application;
  private layers: Map<string, Container> = new Map();
  private textureCache: Map<string, PIXI.Texture> = new Map();
  private scene: SceneData;

  async init(canvas: HTMLCanvasElement) {
    this.app = new Application({
      view: canvas,
      width: 1920,
      height: 1080,
      backgroundColor: 0x1a1a2e,
    });

    // 创建层级容器
    const layerNames = ['background', 'shadows', 'objectsBack', 'characters', 'objectsFront', 'effects', 'ui'];
    layerNames.forEach((name, index) => {
      const container = new Container();
      container.zIndex = index;
      this.app.stage.addChild(container);
      this.layers.set(name, container);
    });

    // 启动渲染循环（PixiJS内置requestAnimationFrame）
    this.app.ticker.add(this.update, this);
  }

  // 纹理缓存：避免重复加载
  private async getTexture(path: string): Promise<PIXI.Texture> {
    if (this.textureCache.has(path)) {
      return this.textureCache.get(path)!;
    }
    const texture = await PIXI.Assets.load(path);
    this.textureCache.set(path, texture);
    return texture;
  }

  // 预加载相邻场景资源
  async preloadConnectedScenes() {
    for (const connected of this.scene.connected_scenes) {
      const sceneData = await fetchSceneData(connected.scene_id);
      await this.getTexture(sceneData.background_image);
    }
  }

  private update(deltaTime: number) {
    // 更新角色动画
    this.updateCharacters(deltaTime);
    // 更新特效
    this.updateEffects(deltaTime);
    // 更新光照
    this.updateLighting(deltaTime);
  }

  // 角色按Y轴深度排序
  private updateCharacters(deltaTime: number) {
    const charLayer = this.layers.get('characters')!;
    charLayer.children.sort((a, b) => a.y - b.y);
  }

  // 释放不可见场景资源
  dispose() {
    this.app.destroy(true);
    this.textureCache.clear();
  }
}
```

## 二、角色移动系统

### 2.1 移动机制

| 输入方式 | 说明 |
|----------|------|
| 点击移动 | 点击地图目标位置，A*寻路后沿路径移动 |
| 方向键/WASD | 按住方向键持续移动，遇障碍停止或绕行 |
| 点击交互点 | 点击NPC/物体，自动移动到附近后触发交互 |

**移动规则：**
- 只能在可行走区域内移动
- 不能穿过障碍物
- 移动速度根据角色属性决定
- 接近交互点时显示交互提示

### 2.2 A*寻路算法（优先队列优化）

```typescript
import { MinHeap } from './MinHeap'; // 自实现最小堆

class PathFinder {
  private grid: Grid;
  private walkableAreas: Polygon[];
  private obstacles: Polygon[];

  findPath(start: Position, end: Position): Position[] {
    if (!this.isWalkable(end)) {
      end = this.findNearestWalkablePoint(end);
    }

    // 使用最小堆替代数组排序，O(log n)取最小值
    const openSet = new MinHeap<Node>((a, b) => a.f - b.f);
    const closedSet = new Set<string>();
    const gScores = new Map<string, number>();

    const startNode = new Node(start, 0, this.heuristic(start, end));
    openSet.push(startNode);
    gScores.set(this.getKey(start), 0);

    while (openSet.size > 0) {
      const current = openSet.pop()!;

      if (this.distance(current.position, end) < this.grid.cellSize) {
        return this.reconstructPath(current);
      }

      const currentKey = this.getKey(current.position);
      if (closedSet.has(currentKey)) continue;
      closedSet.add(currentKey);

      for (const neighbor of this.getNeighbors(current.position)) {
        const neighborKey = this.getKey(neighbor);
        if (closedSet.has(neighborKey)) continue;

        const tentativeG = current.g + this.distance(current.position, neighbor);
        const existingG = gScores.get(neighborKey);

        if (existingG === undefined || tentativeG < existingG) {
          gScores.set(neighborKey, tentativeG);
          const newNode = new Node(
            neighbor,
            tentativeG,
            this.heuristic(neighbor, end),
            current
          );
          openSet.push(newNode);
        }
      }
    }

    return [start, end]; // 找不到路径，返回直线
  }

  // 启发式函数（欧几里得距离，比曼哈顿更准确）
  private heuristic(a: Position, b: Position): number {
    return Math.sqrt(Math.pow(a.x - b.x, 2) + Math.pow(a.y - b.y, 2));
  }

  // 找最近可行走点：限制搜索范围，避免无限循环
  private findNearestWalkablePoint(point: Position): Position {
    const maxRadius = 200; // 限制最大搜索半径
    const step = this.grid.cellSize;

    for (let radius = step; radius < maxRadius; radius += step) {
      for (let angle = 0; angle < Math.PI * 2; angle += Math.PI / 8) {
        const testPoint = {
          x: point.x + Math.cos(angle) * radius,
          y: point.y + Math.sin(angle) * radius
        };
        if (this.isWalkable(testPoint)) return testPoint;
      }
    }
    return point;
  }

  // 路径平滑：减少路径点数量
  private smoothPath(path: Position[]): Position[] {
    if (path.length <= 2) return path;
    const smoothed: Position[] = [path[0]];
    for (let i = 1; i < path.length - 1; i++) {
      const prev = smoothed[smoothed.length - 1];
      const next = path[i + 1];
      if (!this.hasLineOfSight(prev, next)) {
        smoothed.push(path[i]);
      }
    }
    smoothed.push(path[path.length - 1]);
    return smoothed;
  }

  // 射线法判断点在多边形内
  private pointInPolygon(point: Position, vertices: Position[]): boolean {
    let inside = false;
    const { x, y } = point;
    for (let i = 0, j = vertices.length - 1; i < vertices.length; j = i++) {
      const xi = vertices[i].x, yi = vertices[i].y;
      const xj = vertices[j].x, yj = vertices[j].y;
      if (((yi > y) !== (yj > y)) && (x < (xj - xi) * (y - yi) / (yj - yi) + xi)) {
        inside = !inside;
      }
    }
    return inside;
  }
}
```

### 2.3 移动动画

```typescript
class CharacterMovement {
  private currentPath: Position[] = [];
  private pathIndex: number = 0;
  private isMoving: boolean = false;
  private speed: number = 200; // 像素/秒

  moveTo(target: Position) {
    const pathFinder = new PathFinder(this.scene.grid, this.scene.walkableAreas, this.scene.obstacles);
    const path = pathFinder.findPath(this.character.position, target);
    if (path.length > 1) {
      this.currentPath = path;
      this.pathIndex = 0;
      this.isMoving = true;
      this.character.playAnimation('walk');
    }
  }

  // 在PixiJS ticker中调用，基于requestAnimationFrame
  update(deltaTime: number) {
    if (!this.isMoving || this.pathIndex >= this.currentPath.length - 1) {
      if (this.isMoving) this.stopMoving();
      return;
    }

    const target = this.currentPath[this.pathIndex + 1];
    const pos = this.character.position;
    const dx = target.x - pos.x;
    const dy = target.y - pos.y;
    const dist = Math.sqrt(dx * dx + dy * dy);
    const moveDist = this.speed * deltaTime / 60; // deltaTime为帧间隔

    if (moveDist >= dist) {
      this.character.position = { ...target };
      this.pathIndex++;
    } else {
      const ratio = moveDist / dist;
      this.character.position = { x: pos.x + dx * ratio, y: pos.y + dy * ratio };
    }

    this.updateFacing(pos, target);
  }

  private stopMoving() {
    this.isMoving = false;
    this.currentPath = [];
    this.character.playAnimation('idle');
    this.onArrived();
  }

  private onArrived() {
    const nearby = this.scene.getNearbyInteractable(this.character.position, 50);
    if (nearby) this.scene.triggerInteraction(nearby);
  }
}
```

### 3.2 交互流程

```
玩家点击交互点
       │
       ▼
1.检测交互目标（获取点击位置，查找最近交互点）
       │
       ▼
2.检查交互条件（前置条件/道具/冷却）
       │
       ▼
3.移动到交互点附近（A*寻路 + 移动动画）
       │
       ▼
4.显示交互菜单（获取可用动作，等待选择）
       │
       ▼
5.执行交互动作（播放动画，应用效果，触发事件）
       │
       ▼
6.更新游戏状态（玩家/场景/NPC状态）
       │
       ▼
7.生成AI剧情（构建提示词 → 调用AI → 解析结构化输出 → 更新UI）
```

### 7.2 性能优化建议

1. **图片缓存**：PixiJS纹理缓存，避免重复加载；预加载相邻场景资源
2. **地图渲染**：视口裁剪，只渲染可见区域；角色按Y轴排序
3. **寻路优化**：优先队列（最小堆）替代数组排序；预计算静态导航网格
4. **AI响应**：流式输出，显示加载动画
5. **内存管理**：离开场景时释放纹理资源
