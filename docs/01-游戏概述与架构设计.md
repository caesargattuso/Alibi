## 一、游戏概述

### 1.1 游戏定位

一款基于**图文并茂**呈现方式的**AI驱动交互式文字冒险游戏**。玩家通过文字输入与AI生成的场景、角色进行互动，游戏以精美的视觉画面（场景图、角色立绘、UI界面）配合沉浸式文字叙事，打造独特的互动故事体验。

### 1.2 核心特色

| 特色 | 说明 |
|------|------|
| **AI实时生成** | 基于大语言模型，根据玩家输入动态生成剧情 |
| **图文并茂** | 每个场景配有精美背景图，角色配有立绘/头像 |
| **场景地图** | 可视化的场景地图，支持角色在场景中移动 |
| **预制剧本** | 提供多个精心设计的剧本，包含固定场景、角色、规则 |
| **多结局系统** | 根据玩家选择产生不同的剧情分支和结局 |
| **角色关系网** | NPC对玩家的态度动态变化，影响剧情走向 |

### 2.2 架构决策说明

| 决策 | 选择 | 理由 |
|------|------|------|
| **单体优先** | 单体应用，模块化划分 | 项目早期，团队小，单体降低运维复杂度。模块间通过函数调用，后续可拆分为微服务 |
| **不使用MongoDB** | 全部使用PostgreSQL | 对话日志存PostgreSQL即可，JSONB满足灵活字段需求，减少运维组件。如后续日志量极大，可引入ClickHouse做分析 |
| **服务间通信** | 模块间直接函数调用 | 单体架构下无需RPC/消息队列。后续拆分时用gRPC同步调用 + Redis Stream异步通信 |

**核心子系统：**

## 六、错误处理规范

### 6.1 后端异常体系

```python
class AppException(Exception):
    """应用异常基类"""
    def __init__(self, code: int, message: str, detail: dict = None):
        self.code = code
        self.message = message
        self.detail = detail

class ValidationError(AppException):
    """参数校验错误"""
    def __init__(self, message: str, field: str = None):
        super().__init__(400, message, {"field": field})

class AuthError(AppException):
    """认证错误"""
    def __init__(self, message: str = "未授权"):
        super().__init__(401, message)

class ForbiddenError(AppException):
    """权限错误"""
    def __init__(self, message: str = "禁止访问"):
        super().__init__(403, message)

class NotFoundError(AppException):
    """资源不存在"""
    def __init__(self, resource: str):
        super().__init__(404, f"{resource}不存在")

class AIServiceError(AppException):
    """AI服务错误"""
    def __init__(self, message: str = "AI服务暂时不可用"):
        super().__init__(503, message)

class RateLimitError(AppException):
    """请求限流"""
    def __init__(self, message: str = "请求过于频繁"):
        super().__init__(429, message)
```

## 九、安全设计

### 9.1 认证授权

| 方面 | 措施 |
|------|------|
| **JWT** | Access Token 1小时过期，Refresh Token 7天过期 |
| **刷新机制** | Access Token 过期后用 Refresh Token 自动刷新 |
| **密码加密** | bcrypt，cost factor 12 |
| **限流** | API: 100次/分钟/用户，AI: 30次/分钟/用户 |

### 9.2 数据安全

| 方面 | 措施 |
|------|------|
| **传输加密** | 全站HTTPS |
| **输入校验** | Pydantic Schema严格校验所有入参 |
| **SQL注入** | SQLAlchemy参数化查询 |
| **XSS防护** | 前端输出转义，CSP策略 |
| **敏感数据** | 日志脱敏，密码/Token不落库 |

### 9.3 AI安全

| 方面 | 措施 |
|------|------|
| **输入长度** | 单次输入最大500字符 |
| **Prompt注入** | 用户输入包裹在XML标签中，系统提示词标记不可覆盖 |
| **输出审核** | AI回复经过关键词过滤 + 二次分类审核 |
| **内容分级** | 剧本标注内容等级，按等级过滤输出 |
