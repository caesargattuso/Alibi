## 一、模块概述

### 1.1 功能范围

前端组件与交互完善模块负责：
- 自定义Hooks（useAuth, useGame, useScene）
- 游戏核心组件（DialogBox, ChoiceMenu, SceneMap, CharacterPanel）
- 个人中心页面（Profile）
- 工具函数（pathfinding, offline）

### 1.2 组件层级

```
App
├── Home (剧本列表)
├── ScriptDetail (剧本详情)
├── Game (游戏页面)
│   ├── SceneMap (场景地图 - PixiJS)
│   ├── DialogBox (对话显示)
│   ├── ChoiceMenu (选项菜单)
│   └── CharacterPanel (角色面板)
├── Profile (个人中心)
│   ├── 游戏历史
│   ├── 成就展示
│   └── 密码修改
├── Login
└── Register
```

## 二、Hooks设计

### 2.1 useAuth

```typescript
// 封装认证状态和操作
function useAuth() {
  const token = useAuthStore(s => s.token);
  const user = useAuthStore(s => s.user);
  const isAuthenticated = !!token;
  return { token, user, isAuthenticated, login, logout, register };
}
```

### 2.2 useGame

```typescript
// 封装游戏状态和操作
function useGame(sessionId: number | null) {
  const { narration, dialogs, choices, isLoading } = useGameStore();
  return { narration, dialogs, choices, isLoading, sendMessage, sendChoice, quit };
}
```

### 2.3 useScene

```typescript
// 封装场景数据和交互
function useScene(sceneId: number | null) {
  return { scene, mapData, interactables, loadScene, executeInteraction };
}
```

## 三、游戏组件设计

### 3.1 DialogBox

对话显示组件，展示AI生成的叙事文本和角色对话。

**功能：**
- 打字机效果显示叙事文本
- 角色对话卡片（头像+名称+对话内容+情绪标签）
- 自动滚动到最新消息
- 历史对话回看

### 3.2 ChoiceMenu

选项菜单组件，展示AI生成的选择项。

**功能：**
- 2-4个选项按钮
- 自由输入框（最后一个选项为"自由行动"时显示）
- 选中动画效果
- 加载状态

### 3.3 SceneMap

场景地图组件（PixiJS渲染）。

**功能：**
- 场景背景图渲染
- 交互点图标显示
- 点击移动（A*寻路）
- 场景切换过渡动画

### 3.4 CharacterPanel

角色面板组件。

**功能：**
- 角色头像和基本信息
- 属性值显示
- 关系网络展示
