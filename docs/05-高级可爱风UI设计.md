## 一、设计概述

### 1.1 设计定位

参考 UU Game 的设计风格，打造**高级可爱风**的AI互动游戏平台。整体风格既要保持**高级感**（精致、优雅、有品质），又要融入**可爱元素**（柔和、温暖、有亲和力）。

### 1.2 设计关键词

| 维度 | 关键词 |
|------|--------|
| 高级感 | 精致、优雅、品质、简约 |
| 可爱感 | 柔和、温暖、亲和、治愈 |
| 游戏感 | 沉浸、互动、探索、惊喜 |

### 1.3 色彩体系

#### 主色调

| 角色 | 色值 | 色名 | 用途 |
|------|------|------|------|
| Primary | `#FF6B9D` | 粉红 | 主按钮、强调 |
| Secondary | `#4ECDC4` | 青绿 | 次按钮、成功状态 |
| Accent | `#FFE66D` | 明黄 | 警告、点缀 |

#### 中性色

| 角色 | 色值 | 色名 | 用途 |
|------|------|------|------|
| Background | `#FFF5F7` | 浅粉白 | 页面背景 |
| Surface | `#FFFFFF` | 纯白 | 卡片、弹窗 |
| Text | `#2D3436` | 深灰 | 正文文字 |
| Border | `#FFE0E9` | 浅粉 | 边框、分割线 |

#### 渐变

| 名称 | 渐变 |
|------|------|
| Primary | `#FF6B9D → #FF8E9E` |
| Secondary | `#4ECDC4 → #6EE7DE` |

#### 语义色

| 状态 | 色值 | 说明 |
|------|------|------|
| 成功 | `#4ECDC4` | 青绿 |
| 警告 | `#FFE66D` | 明黄 |
| 错误 | `#FF6B6B` | 粉红 |

## 七、剧本封面AI生成

### 7.1 生成流程

1. 用户输入剧本信息（名称、类型、描述、关键词）
2. 构建AI提示词（按类型使用不同模板）
3. 调用SiliconFlow Kolors API生成图片（2-4张备选）
4. 用户选择最满意的一张
5. 上传到云存储（阿里云OSS），保存URL到数据库

### 7.2 提示词模板

```python
COVER_PROMPT_TEMPLATES = {
    "恐怖": "A horror-themed game cover illustration, title: {title}, scene: {description}, keywords: {keywords}, style: high-end cute aesthetic with soft horror atmosphere, delicate details, colors: dark red, deep purple, black, center composition",
    "古风": "A Chinese ancient style game cover illustration, title: {title}, scene: {description}, keywords: {keywords}, style: high-end cute aesthetic with beautiful ancient scene, delicate details, colors: warm yellow, vermillion, ink green, center composition",
    "科幻": "A sci-fi themed game cover illustration, title: {title}, scene: {description}, keywords: {keywords}, style: high-end cute aesthetic with futuristic sci-fi scene, delicate details, colors: blue-purple, silver-white, neon, center composition",
    "悬疑": "A mystery themed game cover illustration, title: {title}, scene: {description}, keywords: {keywords}, style: high-end cute aesthetic with mysterious atmosphere, delicate details, colors: deep blue, gray-white, dark gold, center composition",
    "恋爱": "A romance themed game cover illustration, title: {title}, scene: {description}, keywords: {keywords}, style: high-end cute aesthetic with romantic atmosphere, delicate details, colors: pink, light purple, warm white, center composition",
}
```

> 使用英文提示词以获得更好的图像生成效果。提示词需翻译剧本信息为英文描述。

### 7.3 API调用

```python
# app/services/cover_service.py

import aiohttp

async def generate_cover(prompt: str, count: int = 2) -> list[str]:
    """调用SiliconFlow Kolors API生成封面图"""
    async with aiohttp.ClientSession() as session:
        resp = await session.post(
            "https://api.siliconflow.cn/v1/images/generations",
            headers={"Authorization": f"Bearer {settings.SILICONFLOW_API_KEY}"},
            json={
                "model": "Kolors",
                "prompt": prompt,
                "n": count,
                "size": "1024x576",  # 16:9比例
            }
        )
        data = await resp.json()
        return [item["url"] for item in data["data"]]
```
