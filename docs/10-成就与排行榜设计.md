## 一、成就系统

### 1.1 API设计

```
GET /api/v1/achievements              # 获取所有成就列表
GET /api/v1/users/me/achievements     # 获取当前用户已解锁的成就
```

### 1.2 成就类型

| 类型 | 说明 | 示例 |
|------|------|------|
| game_complete | 完成游戏 | "首次通关" |
| game_count | 游戏次数 | "剧本达人（10局）" |
| ending_unlock | 解锁结局 | "真相大白（解锁真结局）" |
| social | 社交互动 | "评论家（发表5条评论）" |
| special | 特殊成就 | "速通玩家（1小时内通关）" |

### 1.3 成就数据结构

```json
{
  "id": 1,
  "name": "首次通关",
  "description": "完成第一个剧本",
  "icon": "achievements/first_clear.png",
  "condition_type": "game_complete",
  "condition_data": {"count": 1},
  "points": 10,
  "unlocked": true,
  "unlocked_at": "2026-05-30T12:00:00Z"
}
```

### 1.4 成就服务

```python
class AchievementService:
    async def list_all(self, user_id: int | None) -> list[dict]
    async def list_user_achievements(self, user_id: int) -> list[dict]
    async def check_and_unlock(self, user_id: int, condition_type: str, context: dict) -> list[dict]
    async def _check_condition(self, achievement: Achievement, user_id: int, context: dict) -> bool
```

## 二、排行榜系统

### 2.1 API设计

```
GET /api/v1/leaderboards/scripts?period=week&sort_by=play_count&page=1&per_page=20
GET /api/v1/leaderboards/players?period=week&sort_by=completed_games&page=1&per_page=20
```

### 2.2 排行榜类型

| 排行榜 | 排序字段 | 说明 |
|--------|----------|------|
| 剧本热度榜 | play_count | 游玩次数最多 |
| 剧本口碑榜 | rating | 评分最高 |
| 玩家通关榜 | completed_games | 通关数最多 |
| 玩家成就榜 | achievement_points | 成就积分最高 |

### 2.3 时间范围

| 值 | 说明 |
|----|------|
| week | 本周 |
| month | 本月 |
| all | 全部时间 |

### 2.4 排行榜响应

```json
{
  "code": 200,
  "data": {
    "items": [
      {
        "rank": 1,
        "id": 1,
        "title": "后宫大逃杀",
        "cover_image": "covers/palace.jpg",
        "play_count": 1234,
        "rating": 4.5,
        "author": "admin"
      }
    ],
    "total": 50,
    "page": 1,
    "per_page": 20
  }
}
```

### 2.5 排行榜服务

```python
class LeaderboardService:
    async def scripts_leaderboard(self, sort_by: str, period: str, page: int, per_page: int) -> dict
    async def players_leaderboard(self, sort_by: str, period: str, page: int, per_page: int) -> dict
```
