## 一、中间件设计

### 1.1 限流中间件

基于IP的请求限流，防止API滥用。

**策略：**
- 使用令牌桶算法
- 默认：100次/分钟（普通API）
- AI相关接口：30次/分钟
- 通过Redis记录请求计数（无Redis时降级为内存字典）

**实现要点：**
- 中间件在请求处理前检查限流
- 返回429状态码和Retry-After头
- 白名单路径（/docs, /health）不限流

### 1.2 限流响应

```json
{
  "code": 429,
  "message": "请求过于频繁，请稍后再试",
  "data": null,
  "error": {"retry_after": 30}
}
```

## 二、文件上传设计

### 2.1 上传接口

```
POST /api/v1/upload/image   # multipart/form-data
POST /api/v1/upload/audio   # multipart/form-data
```

**请求参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| file | File | 上传的文件 |

**图片限制：**
- 格式：JPG/PNG/GIF/WebP
- 大小：最大5MB
- 尺寸：建议不超过4096x4096

**音频限制：**
- 格式：MP3/OGG/WAV
- 大小：最大10MB

### 2.2 上传响应

```json
{
  "code": 200,
  "data": {
    "url": "/uploads/images/2026/05/30/abc123.jpg",
    "filename": "abc123.jpg",
    "size": 102400,
    "content_type": "image/jpeg"
  }
}
```

### 2.3 存储策略

- 开发环境：本地文件存储（`/uploads/`目录）
- 生产环境：阿里云OSS / MinIO
- 通过环境变量 `STORAGE_TYPE` 切换

### 2.4 文件服务

```python
class FileService:
    async def upload_image(self, file: UploadFile) -> dict
    async def upload_audio(self, file: UploadFile) -> dict
    def _validate_image(self, content: bytes, content_type: str)
    def _validate_audio(self, content: bytes, content_type: str)
    def _generate_filename(self, original: str) -> str
    def _save_local(self, content: bytes, path: str) -> str
```

4. 在 `app/main.py` 中注册中间件和路由
5. 配置静态文件服务
